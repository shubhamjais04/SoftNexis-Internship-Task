# 🧹 Data Cleaning & Preprocessing

A complete data cleaning and preprocessing pipeline built on a real-world customer dataset, transforming raw, inconsistent data into a clean, analysis-ready format.

---

## 📌 Project Overview

Raw data is rarely clean. This project demonstrates a structured approach to diagnosing and fixing real-world data quality issues — handling missing values, removing duplicates, correcting data types, and standardizing formats across a 1,000-record customer dataset.

---

## ✨ What's Covered

- 📥 Data Ingestion — Loading and initial inspection of raw data
- 🔍 Deduplication — Detecting and removing duplicate records
- 🗂️ Column Management — Dropping irrelevant columns and renaming for clarity
- 🩹 Missing Value Handling — Diagnosing and imputing missing entries
- 🔄 Data Type Correction — Converting date columns to proper datetime format
- 📐 Format Standardization — Consistent text casing and whitespace removal
